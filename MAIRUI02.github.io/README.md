# 閲読器作品記録

静态网站发布目录。部署入口为 `index.html`，无需构建命令。

## GitHub Pages

1. 新建公开 GitHub 仓库，名称必须为 `MAIRUI02.github.io`。
2. 上传本目录全部内容（不要额外套一层同名文件夹）。
3. 在仓库 Settings → Pages 中，选择 `Deploy from a branch`，分支选 `main`、文件夹选 `/(root)`。
4. 稍候数分钟后，网站地址为 `https://mairui02.github.io/`。

本目录不含原始 Notion 导出；它们只保留在本机，不应上传至公开仓库。
